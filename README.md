# Drone C0 — Assistant de vol

Application web mobile-first pour préparer un vol de drone C0 en France.

## Fonctionnalités
- Sélection de plusieurs modèles DJI Mini / Neo / Flip.
- Rappels C0 et contrôles pré-vol.
- Géolocalisation du téléphone.
- Carte interactive indicative.
- Accès direct aux sources DGAC, Géoportail et EASA.
- Checklist matériel.
- Compatible GitHub Pages.

## Important
Cette application est un outil d'aide à la préparation. Elle ne constitue pas une autorisation de vol et ne remplace pas les informations officielles, restrictions locales, NOTAM ou consignes des autorités. Vérifier la classe exacte du drone utilisé et les données officielles avant chaque vol.

## Hébergement
Le site est conçu pour être publié comme site statique sur GitHub Pages.
